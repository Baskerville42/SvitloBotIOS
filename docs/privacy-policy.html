Privacy Policy / Політика конфіденційності

Effective date: March 16, 2025

🇬🇧 English Version

This app is a client for the SvitloBot system and does not collect, store, or share any personal information.

  • The app does not require user registration or authentication.
  • No personal identifiers, contact details, or sensitive data are collected.
  • When automatic requests are enabled, the app sends a technical request to a remote server approximately every 60 seconds while internet access is available and the device is charging. If the user enables instant outage notifications, the app attempts to send one additional request when it detects that charging has stopped. The server uses these requests to determine whether electricity is available and may immediately notify the channel when an outage is reported.
  • No data is shared with third parties.
