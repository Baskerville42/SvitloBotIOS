# Support

For usage questions, start with the [SvitloBot documentation site](https://baskerville42.github.io/SvitloBotIOS/) and its [FAQ](https://baskerville42.github.io/SvitloBotIOS/faq.html).

For an app bug or feature request, use the matching issue form in this repository. Include your app version, iOS/iPadOS version, device model, and steps to reproduce. Share only sanitized logs and screenshots.

For account, channel-key, or outage-status questions about the SvitloBot service, contact the service operator through [svitlobot.in.ua](https://svitlobot.in.ua). Telegram delivery and bot-account questions may require [Telegram's support resources](https://telegram.org/support).

Do not include bot tokens, channel keys, private channel identifiers, personal data, or signing credentials in a public issue. Report suspected vulnerabilities using [SECURITY.md](SECURITY.md).
